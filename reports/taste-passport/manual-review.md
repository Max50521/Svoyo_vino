# Ручная проверка «Паспорта вкуса»: 50 карточек

Анализатор `taste-rules@1`. Выборка — 50 из 2103 уникальных вин каталога организаторов (`data/raw/strapi_output0709.csv`), детерминированная (seed 20260928): 17 белых, 17 красных, 10 розовых, 6 оранжевых; внутри цвета — по одной карточке из каждого диапазона длины описания (от самых коротких до самых длинных). Исходные данные выборки с цитатами: [manual-review-sample.json](manual-review-sample.json).

Проверял автор изменений вручную, сравнивая описание с результатом: ложные находки (вывод, которого нет в тексте) и пропуски явных фактов. Это проверка словарного извлечения, а не сенсорная экспертиза сомелье. Шкалы: сладость / кислотность / танины / тело; «—» — в описании не уточнено, в скобках — качество без уровня. Звёздочка у ноты — обобщённая группа («ягоды», «цветы»).
